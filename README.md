# AI Impact on Jobs 2030

An analysis of the impact of artificial intelligence on employment trends and job market evolution through 2030, built with R and Python in RStudio.

## 📊 Dataset

This project uses the [AI Impact on Jobs 2030 Dataset](https://www.kaggle.com/datasets/khushikyad001/ai-impact-on-jobs-2030/data) from Kaggle.

## 📋 Contents

- **Data Analysis** - Exploratory data analysis and statistical insights
- **Visualizations** - Comprehensive charts and graphs showing job market trends
- **Predictions** - Forecasting models for job displacement and creation
- **Reports** - Detailed findings and conclusions

## 🛠️ Technologies

- **R** - Statistical analysis and visualization
- **Python** - Data processing and machine learning
- **RStudio** - Integrated development environment

## 🚀 Getting Started

### Prerequisites
- R (>= 4.0)
- Python (>= 3.8)
- RStudio
